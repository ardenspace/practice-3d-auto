# vanished-worlds 파일럿 관문 1·2 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 이미지 한 장을 2.5D 패럴랙스 무드 영상으로 바꾸는 핵심 기술(깊이 추출 → Blender 카메라 투사 → 루프 렌더)을 구현하고, 설계 문서의 검증 관문 1(10초 패럴랙스 품질 테스트)과 관문 2(2~3분 루프 샷)를 통과한다.

**Architecture:** 깊이 추출(파이썬/Depth Anything V2)과 장면 구축·렌더(Blender 헤드리스 + bpy 스크립트)를 독립 모듈로 나누고, 둘 사이는 파일(깊이 PNG)과 샷 스펙 JSON으로만 통신한다. 렌더는 프리뷰(스틸 1장)와 풀(애니메이션)의 2단계로 분리한다.

**Tech Stack:** Python 3.12+(venv), transformers + torch(Depth Anything V2 Small), Pillow, numpy, pytest, Blender 5.2 LTS 헤드리스(bpy, Eevee), ffmpeg.

**Spec:** `docs/superpowers/specs/2026-09-02-vanished-worlds-design.md`

## Global Constraints

- 유료 API를 호출하지 않는다. 깊이 추출은 로컬 모델, 렌더는 로컬 Blender만 쓴다.
- Blender 실행 파일 경로: `/Applications/Blender.app/Contents/MacOS/Blender` (env `VW_BLENDER_BIN`으로 재정의 가능).
- 장면 자산의 기준 규격: 가로 1920x1080, 24fps. 테스트·프리뷰는 저해상도로 줄여서 돌린다.
- 시스템 파이썬은 3.14인데 torch 휠이 없을 수 있으므로, venv는 3.12로 만든다(`uv venv --python 3.12` 우선, 실패 시 pyenv/homebrew python@3.12).
- 커밋 메시지는 한국어로 쓰고, 각 태스크 끝에서 커밋한다.
- 관문 1과 관문 2의 결과물은 반드시 사용자 승인을 받은 뒤에 다음으로 진행한다. 승인 없이는 후속 계획(전체 파이프라인)을 시작하지 않는다.

```python
"""단일 이미지 깊이 추출 모듈.

모델 교체(Marigold, Depth Pro 등)에 대비해 깊이 추출은 이 모듈 뒤에 숨긴다.
호출자는 extract_depth()의 계약(같은 해상도, 16비트 PNG, 밝음=가까움)만 의존한다.
"""

import sys
from pathlib import Path

import numpy as np
from PIL import Image

MODEL_ID = "depth-anything/Depth-Anything-V2-Small-hf"
_pipe = None


def _get_pipe():
    global _pipe
    if _pipe is None:
        from transformers import pipeline as hf_pipeline

        _pipe = hf_pipeline("depth-estimation", model=MODEL_ID)
    return _pipe


def extract_depth(image_path: Path, out_path: Path) -> Path:
    image = Image.open(image_path).convert("RGB")
    depth = np.array(_get_pipe()(image)["depth"], dtype=np.float32)

    lo, hi = float(depth.min()), float(depth.max())
    norm = (depth - lo) / (hi - lo) if hi > lo else np.zeros_like(depth)

    depth_16bit = Image.fromarray((norm * 65535.0).astype(np.uint16))
    if depth_16bit.size != image.size:
        depth_16bit = depth_16bit.resize(image.size, Image.BILINEAR)

    out_path = Path(out_path)
    out_path.parent.mkdir(parents=True, exist_ok=True)
    depth_16bit.save(out_path)
    return out_path


if __name__ == "__main__":
    extract_depth(Path(sys.argv[1]), Path(sys.argv[2]))
```

- [ ] **Step 1: 샷 스펙 문서 작성** — `pipeline/schemas/shot_spec.md`

````markdown
# 샷 스펙 (shot spec) v1

패럴랙스 샷 하나를 정의하는 JSON. 경로는 프로젝트 루트 기준 상대 경로 또는 절대 경로.

```json
{
  "image": "episodes/pilot-test/assets/source.png",
  "depth": "episodes/pilot-test/assets/depth.png",
  "out_dir": "episodes/pilot-test/renders",
  "name": "shot01",
  "resolution": [1920, 1080],
  "fps": 24,
  "duration_s": 10,
  "depth_strength": 0.35,
  "camera": {"move": "push_in", "amplitude": 0.18, "sway": 0.03, "loop": false},
  "fog_density": 0.06
}
```

- `depth_strength`: 평면 변위 크기(평면 폭 대비 비율 느낌으로 0.2~0.5 권장).
- `camera.amplitude`: 카메라가 다가가는 거리(블렌더 단위). 크면 가장자리 왜곡이 드러난다.
- `camera.sway`: 좌우 흔들림 폭. `camera.loop`이 true면 모든 움직임이 사인 곡선으로 시작점에 되돌아온다.
- `fog_density`: 볼륨 안개 밀도. 0이면 안개 없음.
````

- [ ] **Step 2: bpy 씬 빌더 작성** — `pipeline/blender/parallax_scene.py`

이 파일은 Blender 내장 파이썬으로 실행되므로 venv 패키지를 임포트하면 안 된다(표준 라이브러리 + bpy만).

```python
"""이미지+깊이맵 → 2.5D 패럴랙스 장면 구축과 렌더.

호출: Blender --background --python parallax_scene.py -- <spec.json> <preview|full>
"""

import json
import math
import sys
from pathlib import Path

import bpy

GRID_SUBDIV = 256
CAM_DIST = 2.2  # 평면(폭 2.0)에서 카메라까지의 기본 거리


def parse_args():
    argv = sys.argv[sys.argv.index("--") + 1 :]
    spec = json.loads(Path(argv[0]).read_text())
    return spec, argv[1]


def set_engine(scene):
    prop = scene.render.bl_rna.properties["engine"]
    available = {item.identifier for item in prop.enum_items}
    for engine in ("BLENDER_EEVEE_NEXT", "BLENDER_EEVEE"):
        if engine in available:
            scene.render.engine = engine
            return
    raise RuntimeError(f"Eevee 엔진을 찾지 못했습니다: {available}")


def build_plane(spec):
    image = bpy.data.images.load(str(Path(spec["image"]).resolve()))
    aspect = image.size[0] / image.size[1]

    bpy.ops.mesh.primitive_grid_add(
        x_subdivisions=GRID_SUBDIV, y_subdivisions=GRID_SUBDIV, size=2.0, calc_uvs=True
    )
    plane = bpy.context.active_object
    plane.scale = (1.0, 1.0 / aspect, 1.0)

    depth_tex = bpy.data.textures.new("depth", type="IMAGE")
    depth_tex.image = bpy.data.images.load(str(Path(spec["depth"]).resolve()))
    depth_tex.image.colorspace_settings.name = "Non-Color"
    depth_tex.extension = "EXTEND"

    disp = plane.modifiers.new("parallax", "DISPLACE")
    disp.texture = depth_tex
    disp.texture_coords = "UV"
    disp.direction = "Z"
    disp.mid_level = 0.0
    disp.strength = spec["depth_strength"]

    mat = bpy.data.materials.new("source")
    mat.use_nodes = True
    nodes = mat.node_tree.nodes
    nodes.clear()
    tex_node = nodes.new("ShaderNodeTexImage")
    tex_node.image = image
    emit = nodes.new("ShaderNodeEmission")
    out = nodes.new("ShaderNodeOutputMaterial")
    mat.node_tree.links.new(tex_node.outputs["Color"], emit.inputs["Color"])
    mat.node_tree.links.new(emit.outputs["Emission"], out.inputs["Surface"])
    plane.data.materials.append(mat)
    return plane


def build_fog(spec):
    if spec.get("fog_density", 0) <= 0:
        return
    bpy.ops.mesh.primitive_cube_add(size=4.0, location=(0, 0, CAM_DIST / 2))
    cube = bpy.context.active_object
    mat = bpy.data.materials.new("fog")
    mat.use_nodes = True
    nodes = mat.node_tree.nodes
    nodes.clear()
    vol = nodes.new("ShaderNodeVolumePrincipled")
    vol.inputs["Density"].default_value = spec["fog_density"]
    out = nodes.new("ShaderNodeOutputMaterial")
    mat.node_tree.links.new(vol.outputs["Volume"], out.inputs["Volume"])
    cube.data.materials.append(mat)


def build_camera(spec, frame_end):
    cam_data = bpy.data.cameras.new("cam")
    cam = bpy.data.objects.new("cam", cam_data)
    bpy.context.collection.objects.link(cam)
    bpy.context.scene.camera = cam

    move = spec["camera"]
    amplitude, sway = move["amplitude"], move.get("sway", 0.0)
    loop = move.get("loop", False)

    for frame in range(1, frame_end + 1):
        t = (frame - 1) / max(frame_end - 1, 1)
        if loop:
            # 사인 기반: frame 1과 frame_end+1의 위치·속도가 일치해 이어 붙여도 티가 나지 않는다
            z = CAM_DIST - amplitude * (0.5 - 0.5 * math.cos(2 * math.pi * t))
            x = sway * math.sin(2 * math.pi * t)
        else:
            z = CAM_DIST - amplitude * t  # 등속 푸시인
            x = sway * math.sin(math.pi * t)
        cam.location = (x, 0.0, z)
        cam.keyframe_insert("location", frame=frame)
    return cam


def setup_render(spec, mode):
    scene = bpy.context.scene
    set_engine(scene)
    scene.render.resolution_x, scene.render.resolution_y = spec["resolution"]
    scene.render.fps = spec["fps"]
    scene.frame_start = 1
    scene.frame_end = int(spec["duration_s"] * spec["fps"])

    out_dir = Path(spec["out_dir"]).resolve()
    out_dir.mkdir(parents=True, exist_ok=True)

    if mode == "preview":
        scene.frame_set((scene.frame_start + scene.frame_end) // 2)
        scene.render.image_settings.file_format = "PNG"
        scene.render.filepath = str(out_dir / f"{spec['name']}_preview.png")
        bpy.ops.render.render(write_still=True)
    else:
        scene.render.image_settings.file_format = "FFMPEG"
        scene.render.ffmpeg.format = "MPEG4"
        scene.render.ffmpeg.codec = "H264"
        scene.render.ffmpeg.constant_rate_factor = "HIGH"
        scene.render.filepath = str(out_dir / f"{spec['name']}.mp4")
        bpy.ops.render.render(animation=True)


def main():
    spec, mode = parse_args()
    bpy.ops.wm.read_factory_settings(use_empty=True)
    frame_end = int(spec["duration_s"] * spec["fps"])
    build_plane(spec)
    build_fog(spec)
    build_camera(spec, frame_end)
    setup_render(spec, mode)


main()
```

- [ ] **Step 3: 러너 작성** — `pipeline/render.py`

```python
"""Blender 헤드리스 렌더 러너. 프리뷰(스틸 1장)와 풀(애니메이션)을 분리한다."""

import json
import subprocess
import sys
from pathlib import Path

from pipeline.config import BLENDER_BIN, PROJECT_ROOT

SCENE_SCRIPT = PROJECT_ROOT / "pipeline" / "blender" / "parallax_scene.py"


def render_shot(spec_path: Path, mode: str) -> Path:
    if mode not in ("preview", "full"):
        raise ValueError(f"mode는 preview|full 중 하나여야 합니다: {mode}")

    spec = json.loads(Path(spec_path).read_text())
    suffix = "_preview.png" if mode == "preview" else ".mp4"
    out_path = (PROJECT_ROOT / spec["out_dir"] / f"{spec['name']}{suffix}").resolve()

    if out_path.exists():  # 재실행 안전: 이미 산출물이 있으면 건너뛴다
        return out_path

    subprocess.run(
        [BLENDER_BIN, "--background", "--python", str(SCENE_SCRIPT),
         "--", str(Path(spec_path).resolve()), mode],
        check=True,
        cwd=PROJECT_ROOT,
    )
    if not out_path.exists():
        raise RuntimeError(f"렌더가 산출물을 만들지 못했습니다: {out_path}")
    return out_path


if __name__ == "__main__":
    print(render_shot(Path(sys.argv[1]), sys.argv[2]))
```

```python
"""렌더 시간 실측 기록. 롱폼 렌더 예산 산정의 근거 데이터."""

import json
from pathlib import Path


def record_render(name: str, duration_s: float, wall_clock_s: float,
                  stats_path: Path) -> dict:
    entry = {
        "name": name,
        "duration_s": duration_s,
        "wall_clock_s": wall_clock_s,
        "seconds_per_video_second": round(wall_clock_s / duration_s, 2),
    }
    stats_path = Path(stats_path)
    history = json.loads(stats_path.read_text()) if stats_path.exists() else []
    history.append(entry)
    stats_path.parent.mkdir(parents=True, exist_ok=True)
    stats_path.write_text(json.dumps(history, ensure_ascii=False, indent=2))
    return entry
```

### Task 7: 레이어 분리 2.5D — 관문 1 재도전 (기법 조정)

관문 1 판정에서 단일 평면 부조 방식이 "이미지 확대" 느낌으로 미달했다(원장 참조). 이 태스크는 장면을 깊이 밴드로 분리한 다중 평면으로 재구성해 실제 레이어 간 시차를 만든다. 기존 단일 평면 방식은 `mode: "relief"`로 보존하고, 새 방식은 `mode: "layered"`를 기본값으로 한다. 실행 순서상 Task 5보다 먼저 진행하고, 통과 후 Task 5·6은 layered 모드 기준으로 진행한다.

**Files:**
- Create: `pipeline/layers.py` (깊이 밴드 분리 + 인페인팅)
- Modify: `pipeline/blender/parallax_scene.py` (layered 모드 추가)
- Modify: `pipeline/render.py` (렌더 전에 레이어 산출물 준비)
- Modify: `pipeline/schemas/shot_spec.md` (스펙 v2: mode 필드)
- Modify: `requirements.txt` (`opencv-python-headless` 추가)
- Test: `tests/test_layers.py`, `tests/test_render_layered.py`

**Interfaces:**
- Consumes: Task 2의 깊이 PNG(16비트, 밝음=가까움), Task 3의 `render_shot`/bpy 호출 규약.
- Produces:
  - `pipeline.layers.split_layers(image_path: Path, depth_path: Path, out_dir: Path, n_layers: int = 3) -> Path` — 레이어 메타 JSON 경로를 반환한다. JSON은 `{"layers": [{"png": <경로>, "depth_qmid": <0..1 밴드 중앙값>}, ...]}` 형식이며 가까운 레이어가 먼저 온다. 각 레이어 PNG는 RGBA(전경·중경) 또는 RGB(최원경)다.
  - 샷 스펙 v2: 최상위에 `"mode": "layered" | "relief"` (기본 layered), layered일 때 `"n_layers"` (기본 3). 기존 필드는 유지.
  - `render_shot`은 layered 스펙이면 렌더 전에 `split_layers`를 호출해 레이어 산출물을 만들고(이미 있으면 재사용), bpy 스크립트에 스펙 경로를 그대로 넘긴다. bpy 쪽은 스펙의 `mode`로 분기한다.

**요구 사항 (알고리즘):**

1. **밴드 분리**: 깊이 값의 분위수(예: 3레이어면 33%/66%)로 픽셀을 밴드에 배정한다. 밴드 경계는 수 픽셀 페더링(알파 그라데이션)으로 부드럽게 한다.
2. **인페인팅**: 중경·원경 레이어에서 더 가까운 레이어가 가리던 구멍을 `cv2.inpaint`(반지름 8 내외, TELEA)로 채우고 가장자리를 살짝 블러해 자연스럽게 한다. 최원경 레이어는 구멍 없이 완전히 채운다(알파 불필요).
3. **Blender 배치 기하**: 카메라 시작 위치에서 모든 레이어가 원본 이미지와 동일하게 겹쳐 보여야 한다. 카메라에서 레이어 평면까지 거리 d_i에 대해 평면 폭 w_i = w0 × (d_i / d0)로 스케일하면 화면 footprint가 동일해진다(d0는 기준 레이어 거리). 레이어 거리는 depth_qmid를 [가까움 1.6, 멂 4.5] 범위로 선형 매핑한다.
4. **재질**: 각 평면은 emission + 이미지 알파(블렌드 모드 alpha blend). 평면당 미세한 displace(선택)로 부조감을 남겨도 좋다.
5. **카메라**: 기존 push_in/sway/loop 수식을 재사용하되, layered 모드에서는 amplitude 0.5~0.9가 실용 범위가 되도록 한다(레이어 간 시차가 실제 발생하므로 크게 움직여도 왜곡이 아니라 통과감이 생긴다). 안개 볼륨은 카메라와 원경 사이에 걸치게 유지한다.
6. **루프 호환**: `camera.loop: true`가 layered 모드에서도 기존 수식 그대로 동작해야 한다(관문 2에서 사용).
